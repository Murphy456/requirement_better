# A10 综合交付 · 学员页

用 A01–A09 组成一份有版本的需求包。第一课计划效果观察，第二课用公开案例练迁移，第三课排练交付及答辩。正式时间和成绩规则见 [诊断与结课任务](03_诊断与结课任务.md) 和 [量规](02_评分量规.md)。

为 GOAL-01 选三项指标。写一条暂停护栏，说明数据清理、培训或任务量同时变化时如何解释结果。分开填写实测、计划和假设。课堂演算不作为试点数据。

## 第二课 · 公开 CASE-02 的短练习

使用[公开迁移材料](03_诊断与结课任务.md#公开迁移练习case-02会议室预约)。课内用 7 分钟选择方法。写一个待查原因、一种适合的模型及省略理由、一条领域约束、一条可观察验收、一种无需新增软件的做法。可补一个占用基线获取方法。

本题用于练习。正式计分迁移在第八周独立完成，由讲师首次发放等难变式，时长 90 分钟，第 60 分钟加一项会改变规则的信息。作答覆盖八个维度。

## 第三课 · 一页索引与答辩记录

索引带版次、日期、可点击位置和当前状态。下面是整理顺序，可按你的产物调整。

| 入口 | 指向及版本 | 读者需要核对的内容 |
|---|---|---|
| A01–A03 |  | 原话、问题、证据、推断和待查 |
| A04–A05 |  | 模型、取舍、首版范围 |
| A06–A08 |  | 行为、依赖、验收、评审结论 |
| A09 |  | 追踪、基线、CR-01 与回归影响 |
| A10 |  | 效果观察、个人贡献、反思与下一步 |

课堂用一条链说明决定，再回答一条公开反例，保留个人记录。正式 W4 由评分者另选追问。写下你处理的一项判断、修改依据、剩余未知和一项下一步验证。如用了 AI，注明用在何处、如何人工核查。

核对 [G4](01_阶段任务.md#阶段门)。综合项目占 70%，首次发放的独立迁移占 30%。两份作品分别按八维量规评分，保留 G1–G3 证据和独立答辩记录。
