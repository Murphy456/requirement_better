# A04 业务模型 · 学员页

从 A02 的任务边界起步，用 A03 台账标注依据。三课共用一个模型包。E02、E04、E06 都已经在前课投放。第二课另发统一练习规则，供推演使用。

## 第一课 · 现状和目标各画一遍

复读 E02。按角色画出选工单、复制、缺号查询和台账比对的路径。图的终点是该次观察的终点。把尚未观察的分支、未明确的责任和候选改进另作标记。

| 现状或候选目标 | 角色 | 输入和动作 | 产出或移交对象 | 异常去向 | 依据或待确认 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

交两张小图或两组步骤。展现一次人工交接和一条缺号分支。课后补起止、交接内容和一条异常路径。

## 第二课 · 练习规则卡

以下 BR 条目来自模拟协商口径。E03 给出了案例授权规则，其余细化均作为教学条件。现实项目需要确认适用口径和决策角色。 [来源与参考业务模型](../03_贯穿案例/02_分析与建模参考.md)

| ID | 本课使用的条件 |
|---|---|
| BR-01 | 限当前授权园区。申请、生成、下载检查权限。下载时范围失效，拒绝整个文件并提示重新申请 |
| BR-02 | Asia/Shanghai 当月首日 00:00 起，至次月首日 00:00 止，包含起点，排除终点 |
| BR-03 | 以申请被接受的快照时点为准，选当时已关闭且最近关闭时间在选月的工单 |
| BR-04 | 主管批准重开，状态转为处理中，清空当前最近关闭时间，保留历史事件。再次关闭写入新的当前时间 |
| BR-05 | 资产编号缺失保留空值并标记，由业务协作核实。禁用猜测值 |
