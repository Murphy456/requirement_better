# M04 业务建模与规则

对应能力 C04 与成果 A04。承接 A02 修订稿与 A03 台账，把同一任务分别表达为业务流程、工单状态及筛选规则。三课各 25 分钟。E02、E04、E06 沿用前课材料。L04.02 发 BR-01 至 BR-05 统一练习口径。新增口径来自模拟协商，尚未固化为学员的项目决定。

课前准备 [学员页](../04_练习与评价/A04_业务模型_学员页.md) 和 [参考样件](../04_练习与评价/A04_业务模型_参考样件.md)，按时投放作答区与当节材料。方法见 [核心知识](../01_知识体系/K04_业务建模与规则.md) 和 [工作模板](../05_工作模板/T03_业务模型与规则.md)，概念来源见 [SRC-02、SRC-03](../07_参考资料/01_来源登记.md)。

## L04.01 用流程看见交接与返工

能分别画出现状和候选目标流程，保留一个人工交接与一个异常分支。 [完整讲稿](../10_完整讲稿/M04/L04.01_用流程看见交接与返工.md)

| 时间 | 课堂活动与检查 |
|---|---|
| 00–03 | 从 E02 找遗漏的交接。 |
| 03–13 | 沿观察窗口建现状，走缺号与未查到分支，以候选快照画目标。 |
| 13–20 | 两张小图互查，标明 E02 与推演。 |
| 20–25 | 用一个缺号输入走读，并记录责任或来源缺口。 |

讲评重点。将观察终点写成已结算时，回到 E02 重新收窄。把尚未观察的分支和新做法标为候选。

## L04.02 状态、数据与规则怎样互相约束

能给有效和非法转换写条件、责任与结果，并说明当前字段、历史事件和月份边界。 [完整讲稿](../10_完整讲稿/M04/L04.02_状态数据与规则怎样互相约束.md)

| 时间 | 课堂活动与检查 |
|---|---|
| 00–03 | 区分班组完工与主管确认。 |
| 03–13 | 投放练习规则卡，示范有效转换、非法动作、清空当前时间与保留历史，演算月界。 |
| 13–20 | 填状态及字段表，互相只按模型推导。 |
| 20–25 | 收一个非法转换和一条月份口径，用未获批准的重开讲评。 |

讲评重点。如果重开删除了原历史记录，指出当前字段与历史事件各自的职责。核对时区与起止边界。

## L04.03 模型如何帮助发现遗漏

能用 WO-106 推导两个假设时点的输出，指出跨模型冲突和确认责任。 [完整讲稿](../10_完整讲稿/M04/L04.03_模型如何帮助发现遗漏.md)

| 时间 | 课堂活动与检查 |
|---|---|
| 00–03 | 先独立判断 11 月 3 日申请十月快照。 |
| 03–13 | 沿 E06 时间线走读流程、状态和规则，再检查「十月已结算」表述。 |
| 13–20 | 填写两次查询和一处冲突，与同伴找分歧。 |
| 20–25 | 交两行走读及一项待确认，作为 M05 方案讨论的依据。 |

讲评重点。参考条件设两次都具备 A 园区授权。10 月 31 日仅做假设查询，不能写成真实导出记录。

## 阶段提交与反馈

提交现状与候选目标流程、最小状态和字段表、月份和授权规则，以及 WO-106 的交叉核对。交给 M05 时把固定月度结算用途和未定责任保留为待确认。按量规核对模型的状态、字段和规则能否解释同一输入。课内用短句和表格演算，课后补全规则、字段出处及异常。 评价锚点见 [R3](../04_练习与评价/02_评分量规.md)。
