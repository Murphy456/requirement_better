# M07 质量数据与过渡

对应能力 C07 与成果 A07。把 A06 的工作承诺补成可测的质量条件、数据和访问规则及试点准备。三课各 25 分钟。Q-01 至 Q-03 为教学参考，数值、环境和期限的实际采用状态须注明。

课前准备 [学员页](../04_练习与评价/A07_质量与依赖_学员页.md) 和 [参考样件](../04_练习与评价/A07_质量与依赖_参考样件.md)，先发作答区，再出示当节示例。方法见 [核心知识](../01_知识体系/K07_质量数据与过渡.md)、[工作模板](../05_工作模板/T06_质量与依赖.md)，概念出处见 [SRC-01、SRC-04](../07_参考资料/01_来源登记.md)。

## L07.01 把“快、稳、好用”变成条件

能写对象、负载、计时、统计与测量方法，解释失败和未完成如何处理。 [完整讲稿](../10_完整讲稿/M07/L07.01_把快稳好用变成条件.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 从「两秒」问起止、规模和使用情境。 |
| 03–13 | 写 Q-01 测量条件，用 94、3、2、1 分组数据识别分母问题。 |
| 13–20 | 写质量候选要求，两人分别复核业务容忍度与可测性。 |
| 20–25 | 核对结果与试点业务效果，收待协商项。 |

数字来自教学算例，不当作实测。失败、超时和未完成均计入约定分母。

## L07.02 数据、权限和接口也是业务需求

能写字段含义、来源、缺失处理、访问阶段以及外部信息不可用时的候选行为。 [完整讲稿](../10_完整讲稿/M07/L07.02_数据权限和接口也是业务需求.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 比较 WO-102 的空值、零值和猜测编号。 |
| 03–13 | 演示最小字段表、三阶段授权和外部授权数据不可用。 |
| 13–20 | 写两行字段与两个撤权情境，标接口确认角色。 |
| 20–25 | 用缺号与撤权分别走读，收一项接口待确认。 |

工单标识缺失与资产编号空值后果不同。权限范围未知时不启动带数据试点。

## L07.03 上线前有哪些临时但必要的要求

能区分临时准备与长期要求，写切换、回退和恢复条件。 [完整讲稿](../10_完整讲稿/M07/L07.03_上线前有哪些临时但必要的要求.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 问试点启动前哪项工作要先验。 |
| 03–13 | 列初次授权与培训，检查存量数据兼容、依赖、未完成影响和越权回退。 |
| 13–20 | 选两项准备、一项持续要求，互走暂停及替代路线。 |
| 20–25 | 收准备证据、阻断项和恢复责任。 |

不假定要迁移全部记录，保留现有获授权流程，已生成材料按确认规则处置。

## 阶段提交与反馈

交质量场景、数据与权限字典、接口异常候选、过渡计划和试点阻断清单。给每个未决项标责任和完成证据，随 A06 进入 M08。 评价锚点见 [R5](../04_练习与评价/02_评分量规.md)。
