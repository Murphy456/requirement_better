# M05 方案比较与优先级

对应能力 C05 与成果 A05。用 A02 的目标、A03 的证据和 A04 的模型比较做法，写出取舍与首版范围。三课各 25 分钟。允许采用不同方案。第三课在模拟确认 H03 的前提下，用 DEC-01 示范一份连续的范围决策。

课前准备 [学员页](../04_练习与评价/A05_范围决策_学员页.md) 和 [参考样件](../04_练习与评价/A05_范围决策_参考样件.md)，按时投放作答区与当节材料。方法见 [核心知识](../01_知识体系/K05_方案比较与优先级.md) 和 [工作模板](../05_工作模板/T04_方案与范围.md)，概念来源见 [SRC-01、SRC-03](../07_参考资料/01_来源登记.md)。

## L05.01 同一目标可以怎样实现

能在同一目标和约束下比较至少两案，其中一案从人工流程改起。 [完整讲稿](../10_完整讲稿/M05/L05.01_同一目标可以怎样实现.md)

| 时间 | 课堂活动与检查 |
|---|---|
| 00–03 | 用 WO-102 问导出能否消去空格。 |
| 03–13 | 共定授权、任务和目标，比较人工核实、受控导出及跨系统集成。 |
| 13–20 | 写两案的贡献、成本、依赖、风险及残留工作。 |
| 20–25 | 检查谁承担剩余工作和什么新条件会改变选择。 |

讲评重点。若写人工方案无成本，要求补实际操作和交接。对于集成保留独立调研条件。

## L05.02 优先级怎样从意见变成决策

能先检查必要约束，再基于价值、风险、成本与依赖排序，并写复议条件。 [完整讲稿](../10_完整讲稿/M05/L05.02_优先级怎样从意见变成决策.md)

| 时间 | 课堂活动与检查 |
|---|---|
| 00–03 | 用低频权限问题挑战收益排序。 |
| 03–13 | 对照 E03 和 BR-01，看权限如何约束申请、生成和下载，试排四项。 |
| 13–20 | 分组排序并互查一条依赖，保留一个新发现触发的改动。 |
| 20–25 | 收一项硬条件、一条依赖和一项复议条件。 |

讲评重点。不按单一分数排权限。说明可并行编写与必须同时交付的区别。

## L05.03 把范围切成能验证的首版

能划出一条可验证的首版路径，包含关键异常、保护条件和试点停止条件。 [完整讲稿](../10_完整讲稿/M05/L05.03_把范围切成能验证的首版.md)

| 时间 | 课堂活动与检查 |
|---|---|
| 00–03 | 用一个异常检查只有导出按钮的范围。 |
| 03–13 | 走 WO-102、WO-106，补空结果、撤权、失败及重试。区分交付行为与字段完整性。 |
| 13–20 | 填首版、后续、范围外和两类验证，互走一次异常。 |
| 20–25 | 收 A05 范围、风险与复议记录，进入 W2 和 G2。 |

讲评重点。缺号提示不意味着编号已经补全。实际性能、保留期限与收益目标由后续确认。

## 阶段提交与反馈

提交至少两个方案的比较和优先级、必备约束、首版及异常、后续或范围外事项、验证和停止条件。用 A04 和 A05 参加 [W2 方案协商](../00_课程设计/04_教学与试点方案.md) 与 [G2](../04_练习与评价/01_阶段任务.md#阶段门)。若还走不完一次任务，先补模型或调整边界。将确认的范围、规则和仍待核实的条件传给 M06。 评价锚点见 [R4](../04_练习与评价/02_评分量规.md)。
