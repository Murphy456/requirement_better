# M09 追踪基线与变更

对应能力 C09 与成果 A09。承接 A06–A08 及评审决定。三课各 25 分钟。先建立可顺查和倒查的关系，再接收 CR-01，最后记录状态、版本和复议条件。L09.02 才发变更卡。

课前准备 [学员页](../04_练习与评价/A09_变更影响_学员页.md) 和 [参考样件](../04_练习与评价/A09_变更影响_参考样件.md)，先发作答区，再出示当节示例。方法见 [核心知识](../01_知识体系/K09_追踪基线与变更.md) 与 [T08](../05_工作模板/T08_追踪变更与效果.md)，概念出处见 [SRC-02、SRC-03](../07_参考资料/01_来源登记.md)。

## L09.01 让需求的来龙去脉可查

能用编号和关系说明从目标、证据、决定到需求及验收的链，并从场景逆查。 [完整讲稿](../10_完整讲稿/M09/L09.01_让需求的来龙去脉可查.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 从下载前撤权问出处。 |
| 03–13 | 示范 GOAL-01 到 REQ-01、AC-01；从 AC-06 逆查 REQ-03 和 E03，再回找 AC-09。 |
| 13–20 | 填一条顺查和一条倒查，互看出处与关系。 |
| 20–25 | 收主链及一项待补关系。 |

同一场景可验证多个需求；只做有用连接，明确编号、含义与版次。

## L09.02 变更影响如何分析

能解释 CR-01 的新旧差异、影响、未知、备选及回归范围。 [完整讲稿](../10_完整讲稿/M09/L09.02_变更影响如何分析.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 发 CR-01，圈出新增业务动作。 |
| 03–13 | 比较导出与回写结算，走读权限、状态、数据、恢复、质量及计划，区分新验收与旧回归。 |
| 13–20 | 写至少两种处理、责任及复议条件，互查一条回归理由。 |
| 20–25 | 收暂定决定和重审范围。 |

区分同意调研、批准写入和实际排期。对共享授权或快照按影响复核。

## L09.03 基线和版本怎样支持协作

能给状态转换指定角色和证据，用版本及例外记录说明当前决定。 [完整讲稿](../10_完整讲稿/M09/L09.03_基线和版本怎样支持协作.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 问「已确认」对应哪份记录。 |
| 03–13 | 回查 v0.1 的适用范围，走六类状态和临时暂停例外。 |
| 13–20 | 为状态填条件、角色与证据，为 CR-01 记当前结论。 |
| 20–25 | 收决定、版次与重审条件。 |

确认与排期分别记录，撤回保留理由，行为验证和效果观察分开。

## 阶段提交与反馈

提交 A09 追踪矩阵、CR-01 处理及回归范围、版本与状态规则。把教学走读、已确认范围、已交付与已验证等状态区分后交 M10。 评价锚点见 [R7](../04_练习与评价/02_评分量规.md)。
