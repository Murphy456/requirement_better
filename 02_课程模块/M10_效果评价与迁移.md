# M10 效果评价与迁移

对应能力 C10 与成果 A10。三课各 25 分钟。先给 GOAL-01 定测量方法，用公开 CASE-02 练方法选择，最后排练交付。独立计分迁移在第八周另外安排 90 分钟，讲师首次发放等难变式。

课前准备 [学员页](../04_练习与评价/A10_综合交付_学员页.md) 和 [参考样件](../04_练习与评价/A10_综合交付_参考样件.md)，先发作答区，再出示当节示例。方法见 [核心知识](../01_知识体系/K10_效果评价与迁移.md) 与 [T08](../05_工作模板/T08_追踪变更与效果.md)，概念出处见 [SRC-01、SRC-06](../07_参考资料/01_来源登记.md)。

## L10.01 做完以后怎样知道有用

能分别定义功能、使用、业务结果，写清分母、时间窗、取证与停止条件。 [完整讲稿](../10_完整讲稿/M10/L10.01_做完以后怎样知道有用.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 比较下载事件与真实准备任务。 |
| 03–13 | 演示验收、任务使用率、操作时间与返工，给任务未判定和同时变化的反例。 |
| 13–20 | 写三层指标与基线获取方式，互查分母及暂停条件。 |
| 20–25 | 收一项基线采集与一个触发决定。 |

样例数字供计算。E02 未连续计时；前后变化有多种解释。

## L10.02 把方法迁移到陌生业务

能在公开 CASE-02 中根据约束选模型和可观察验收，解释省去的做法。 [完整讲稿](../10_完整讲稿/M10/L10.02_把方法迁移到陌生业务.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 用行政陈述找原因假设。 |
| 03–13 | 比较空间、爽约与信息问题，走开放时段、冲突与访客例外，比较人工协调和系统方案。 |
| 13–20 | 七分钟写待查、模型、省略、业务规则及验收，补人工选项。 |
| 20–25 | 收方法选择及理由，说明正式计分安排。 |

公开题仅练习。正式计分为首次发放的 90 分钟独立变式，在第 60 分钟注入变更。

## L10.03 交付一个经得起追问的需求包

能用索引和一条证据链答复反例，解释个人贡献、未知项及重审范围。 [完整讲稿](../10_完整讲稿/M10/L10.03_交付一个经得起追问的需求包.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 请新接手的人找决定和验收。 |
| 03–13 | 演示索引、授权来源不可用的反例及评分反馈。 |
| 13–20 | 两人短答，保留个人判断、影响与出处。 |
| 20–25 | 核对正式提交、W4 与 G4，标下一步证据。 |

能定位个人贡献，保留未决事项。用统一八维量规评综合和独立迁移。

## 阶段提交与反馈

提交有版本的 A01–A10 索引、CR-01 处理、效果计划和个人答辩记录。正式任务见 [诊断与结课任务](../04_练习与评价/03_诊断与结课任务.md)，以 [W4](../00_课程设计/04_教学与试点方案.md) 与 [G4](../04_练习与评价/01_阶段任务.md#阶段门) 复核。综合项目 70%，独立计分迁移 30%。 评价锚点见 [R8](../04_练习与评价/02_评分量规.md)。
