# M08 需求确认与验收

对应能力 C08 与成果 A08。用 A06 与 A07 走读表达、业务需要和实现，再补可复现的验收场景并演练联合评审。三课各 25 分钟。案例参考可用于讨论，走读结论与真实发布决定分别记录。

课前准备 [学员页](../04_练习与评价/A08_评审验收包_学员页.md) 和 [参考样件](../04_练习与评价/A08_评审验收包_参考样件.md)，先发作答区，再出示当节示例。方法见 [核心知识](../01_知识体系/K08_需求确认与验收.md)、[工作模板](../05_工作模板/T07_评审与验收.md)，概念出处见 [SRC-08、SRC-07](../07_参考资料/01_来源登记.md)。

## L08.01 检查写得对，也检查需不需要

能区分表达质量、业务需要与实现验收，为每项找参与角色和证据。 [完整讲稿](../10_完整讲稿/M08/L08.01_检查写得对也检查需不需要.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 对「能生成，但不好用」分别拟追问。 |
| 03–13 | 拿 REQ-01 同做口径盲读、财务走任务及按 E05 判断实现结果。 |
| 13–20 | 写三类检查各一问、一角色、一证据，互查匹配度。 |
| 20–25 | 把「整体通过」改为有条件的结论。 |

已验证单一行为没有覆盖实际业务效果。出处不够时写后续证据。

## L08.02 用实例写出可观察的验收条件

能用前提、事件、结果复现授权变化和跨期反例。 [完整讲稿](../10_完整讲稿/M08/L08.02_用实例写出可观察的验收条件.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 补「正确下载」的动作前条件。 |
| 03–13 | 走 AC-01 成功、生成中和下载前撤权以及 WO-106；补月界的可比前提。 |
| 13–20 | 写三条实例并关联条目，互相检查能否复现。 |
| 20–25 | 补另一个权限阶段、其他异常，测量条件引用 A07。 |

AC-06 是已生成后，AC-09 是生成中，保持结果与检查阶段一致。

## L08.03 组织一次有结论的联合评审

能登记冲突、阻断和建议，给出带版本、决定者和复审范围的结果。 [完整讲稿](../10_完整讲稿/M08/L08.03_组织一次有结论的联合评审.md)

| 时间 | 活动与产出 |
|---|---|
| 00–03 | 问「整体通过」缺哪个可执行信息。 |
| 03–13 | 让业务、交付、测试走同一输入，再按影响分级未决项，示范版本和复审约定。 |
| 13–20 | 做短评审，写一项阻断、一项建议和有条件的结论。 |
| 20–25 | 收结论及重审范围，课后完成 W3 与 G3 复核。 |

可以同意继续课堂走读并暂缓带数据试点。实际基线和上线需要对应决定与证据。

## 阶段提交与反馈

提交三类检查计划、关键需求的验收场景、已定与未决事项及版本记录。参加 [W3 联合评审](../00_课程设计/04_教学与试点方案.md)，按 [G3](../04_练习与评价/01_阶段任务.md#阶段门) 复核。把 A06–A08、适用范围与重审条件交 M09。 评价锚点见 [R6](../04_练习与评价/02_评分量规.md)。
