# M02 目标范围与干系人

对应能力 C02 和成果 A02。三课各 25 分钟，学员带上 M01 的需求层次图和优先待查项。先写一份能指导调查的问题简报，再标明角色、决策责任和首版候选边界。M03 根据新证据修订同一份简报。

课前准备 [A02 学员页](../04_练习与评价/A02_问题简报_学员页.md)和[参考样件](../04_练习与评价/A02_问题简报_参考样件.md)。E02 在第一课发，E04 在第二课发，E01 和 E03 从 M01 沿用。参考样件只展示当节内容。可复用 [T01 问题定义与角色](../05_工作模板/T01_问题定义与角色.md)，理论和方法读 [K02](../01_知识体系/K02_目标范围与干系人.md)，概念来源见 [SRC-01、SRC-03](../07_参考资料/01_来源登记.md)。

## L02.01 把问题写到可以开始调查

学员能用角色、任务、现状差距、影响和调查范围写出问题，并标出事实与待验证原因。 [完整讲稿](../10_完整讲稿/M02/L02.01_把问题写到可以开始调查.md)

| 时间 | 课堂活动 | 产出或检查 |
|---|---|---|
| 00–03 | 圈出「缺月度报表，财务效率低」中待查的词 | 回看 A01，选一个可追问的切入点 |
| 03–13 | 发 E02，复述一次实际做法，比较 E01 的经办陈述 | 将单次观察与频率、耗时推测分开，示范一段问题说明 |
| 13–20 | 写三四条短句，互查来源，修订带假设的句子。课后整理成约 150 字 | A02 问题段落、一次修改和一项追加调查 |
| 20–25 | 讲评「每次都慢」「数据没打通」 | 能指出要找谁、看什么、判断什么 |

若学生只写缺功能，让他补上最近一次任务。若把推测写成事实，让他逐句回指原料，再改成候选解释。

## L02.02 找到真正需要参与决策的人

学员能区分实际使用、执行影响、预算审批、业务口径和交付判断，安排一次有明确对象的协商。 [完整讲稿](../10_完整讲稿/M02/L02.02_找到真正需要参与决策的人.md)

| 时间 | 课堂活动 | 产出或检查 |
|---|---|---|
| 00–03 | 各自写两位参会者，说明少了其中一位会缺什么 | 识别一位经办之外的角色 |
| 03–13 | 发 E04，区分班组的陈述、顾虑与待核实规则，讨论财务与返修的冲突 | 说清谁提供记录、谁确认口径、谁估交付 |
| 13–20 | 填至少四个角色及两步协商安排，互查还有谁受影响 | A02 角色表，遗漏的角色标补请条件 |
| 20–25 | 讲评如何处理班组录入负担和预算授权缺口 | 至少写一处会改变参会名单或决策分工的理由 |

涉及预算时标待确认的授权链。涉及具体重开权限与月份规则时保留核实对象。

## L02.03 界定范围和成功标准

学员能写出调查边界、外部依赖和暂停条件，并分别提出行为验收与效果观察。 [完整讲稿](../10_完整讲稿/M02/L02.03_界定范围和成功标准.md)

| 时间 | 课堂活动 | 产出或检查 |
|---|---|---|
| 00–03 | 比较核对准备与自动结算的额外角色和动作 | 标识一次范围扩大 |
| 03–13 | 画工单、台账、财务处理三处边界，示范验收与度量 | 以 E03 检查授权约束，示范起止、周期、基线与负责人 |
| 13–20 | 写范围内外、依赖、验收与效果观察，互查暂停条件 | A02 范围与目标栏，保留未确认的目标值 |
| 20–25 | 对比两份范围，收初版和一个优先待查项 | 给 M03 留出可调查的问题 |

按 [R1](../04_练习与评价/02_评分量规.md) 反馈角色、情境、目标及范围。A02 完整初版要能回答「谁的问题、有什么影响、谁能确认」。课内可先写关键词，课后补成可阅读的简报。实际耗时、收益和适用范围缺数据时留待查，不先定数字。
