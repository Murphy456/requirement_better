# 三节样课

S01、S02、S03 讲稿统一使用[招聘助手案例](../03_贯穿案例/招聘助手/00_案例说明.md)，已配套独立 HTML 试讲课件。每节 25 分钟，包括讲解、练习、讨论和反馈。

准备授课时，按每节讲稿发放[模拟材料](../03_贯穿案例/招聘助手/01_模拟材料.md)与[学员作答区](../03_贯穿案例/招聘助手/02_试讲学员页.md)。独立作答后展示[讲评参考](../03_贯穿案例/招聘助手/03_讲评参考.md)。

| 样课 | 对应课时 | 用来验证什么 |
|---|---|---|
| [S01 从一句自动刷简历的诉求开始](../10_完整讲稿/M01/L01.01_一句诉求里有几层意思.md) | L01.01 | 能否教会区分事实、需要与方案 |
| [S02 五份简历记录支持什么结论](../10_完整讲稿/M03/L03.02_观察记录和数据怎样互相校验.md) | L03.02 | 能否教会证据限制与反证 |
| [S03 把简历打分要快写成可验收要求](../10_完整讲稿/M07/L07.01_把快稳好用变成条件.md) | L07.01 | 能否连接业务任务和可测量要求 |

先使用[试点方案](../00_课程设计/04_教学与试点方案.md)进行小规模试讲，再根据作品与评分修订。讲师不应预先告诉学员所有参考结论。
