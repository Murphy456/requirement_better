# Requirement Better · 需求工程课程知识库

**面向产品与业务人员，从理解需求的本质，到交付可验证的需求。**

这里把需求工作作为完整工程实践：解释业务目标，获取证据，建立模型，协商范围，表达要求，确认与验收，管理变化，再检查实际效果。课程采用一个贯穿案例，配合陌生情境练习，训练判断与协作。

## 从这里开始

- **看课程设计**：[总设计](00_课程设计/01_课程总设计.md) → [能力与评价矩阵](00_课程设计/02_能力与评价矩阵.md) → [30课课程地图](00_课程设计/03_课程地图.md)。
- **开始学习**：从[M01需求本质与层次](02_课程模块/M01_需求本质与层次.md)进入，按[阶段任务](04_练习与评价/01_阶段任务.md)逐步完成同一个需求包。
- **准备授课**：阅读[教学与试点方案](00_课程设计/04_教学与试点方案.md)、[贯穿案例](03_贯穿案例/00_案例说明.md)、[评分量规](04_练习与评价/02_评分量规.md)和[三节样课](09_样课/README.md)。
- **工作中查用**：按[方法选择](07_参考资料/03_方法选择.md)找到知识与模板，使用[AI辅助规则](06_AI辅助/01_使用规则.md)和[任务提示词](06_AI辅助/02_任务提示词.md)。

## 本版交付与边界

版本：1.0，2026-11-16。包含 10 个模块、30 节课的教学设计，10 篇核心知识、贯穿案例、工作模板、作业量规和 AI 辅助提示词。

教材制作进度。M01–M03 已完成 9 节逐课设计与完整讲稿，配有 [A01 需求层次图](04_练习与评价/A01_需求层次图_学员页.md)、[A02 问题简报](04_练习与评价/A02_问题简报_学员页.md)和 [A03 证据台账](04_练习与评价/A03_证据台账_学员页.md)。M07 保留一份样稿。实际试讲待安排。可按模块查阅讲稿。

- [M01 需求本质与层次](02_课程模块/M01_需求本质与层次.md)
- [M02 目标范围与干系人](02_课程模块/M02_目标范围与干系人.md)
