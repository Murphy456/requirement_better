# A05 范围决策 · 学员页

沿用 A02 的目标、A03 的证据及 A04 的业务模型。三课将比较、排序与首版范围放进同一份决策记录。先写方案和条件，最后再看教学参考取舍。

## 第一课 · 比较两种完整做法

共同目标写成一句话。用同一授权园区和核对准备任务作为比较对象。至少有一案从现有人工作法或责任安排改起。用 E05 的 WO-102 检查，每案遇到编号缺失时谁负责核实。

| 方案 | 对目标贡献 | 成本及依据 | 依赖 | 风险 | 仍要做的工作 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |

还可记录跨系统集成方案。成本或收益缺实测依据时，写出要请谁核实，暂不填数字。

## 第二课 · 先查约束，再排优先级

对字段补录协作、权限控制、受控导出、自动回写分组或排序。检查 E03 和 BR-01。若一项必须条件无法确认，写清暂停哪个动作。

| 项目 | 必须满足、首版候选、后续或范围外 | 价值和风险 | 成本与依赖 | 决定角色与复议条件 |
|---|---|---|---|---|
|  |  |  |  |  |

可以将有关联的工作放在同一批交付。给出一个会改变顺序、暂停试点或改变首版范围的发现，并写清谁有权决定。
