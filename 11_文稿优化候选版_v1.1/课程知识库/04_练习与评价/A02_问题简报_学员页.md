# A02 问题简报 · 学员页

从 A01 选一个优先待查项。三节课连续修改同一份简报，先用 E01–E04 完成初版，M03 领到新材料后再补修订。两张新卡由讲师按课时提供。上课时只发当前卡和作答区。

## 第一课 · 写一段能调查的问题

**E02 一次核对准备的观察记录，L02.01 发放**

> 模拟观察窗口为2026-11-03上午的一次工作过程：经办选择10月工单，复制列表到本地表格，发现部分工单没有资产编号，联系班组查询，再比对资产台账。记录没有连续计时，也没有覆盖其他经办人员。可证明案例中存在这些步骤，不能据此计算平均耗时。

课堂先写三到四条短句，课后整理成约 150 字。交代角色、任务、当前做法与差距、影响和下一步调查。每个关键事实标出 E01 或 E02。把推测原因和未知数字放进待查项。最后补一句「我会请____提供____，用来判断____。」

保留一个修改痕迹「我原来写____，现在改为____，因为____。」

## 第二课 · 找到要参加决定的人

**E04 维修班组的说明，L02.02 发放**

> 完工之后还有主管确认。关闭的单如果又出问题，主管会重新打开。我们希望能处理返修，不想为了月底报表把状态锁死。

这是班组的陈述。实际重开权限、事件记录和月份规则需向相关角色核实。

| 角色 | 关心什么或承担什么影响 | 能提供的材料 | 能决定什么或需要向谁确认 |
|---|---|---|---|
|  |  |  |  |

选至少四个角色。另写一段两步协商安排。财务希望月度材料有清楚口径，班组希望返修仍能处理。你先向谁了解什么，再请谁组织确认？若涉及预算和审批，标出目前缺少的授权信息。

## M03 后修订

用 A03 的证据台账检查原简报。留一条前后记录，包含原判断、新材料、修订后的说法、受影响的决定及下一步。保留未确认问题。
