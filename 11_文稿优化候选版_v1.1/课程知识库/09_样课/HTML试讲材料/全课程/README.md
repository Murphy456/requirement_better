# 需求工程 · 全课程 HTML 试讲课件

10 个模块共 30 节，每节按 25 分钟安排。三节样课可单独试讲。全课程按 M01–M10 的顺序使用，并配合 A01–A10 完成案例成果。

课件采用招聘助手教学案例，材料、规则示例和数字供课堂讨论。L10.02 用 MIG-01 会议室预约做公开迁移练习。案例进展、评分权重、授权范围等真实项目事项以实际确认结果为准。

## 投屏准备

1. 在 GitHub 文件页下载原始 HTML，用桌面浏览器打开。每节可独立运行。
2. 方向键或底部按钮翻页，N 切换讲者备注。「全屏」用于投屏。答完题后再揭示讲评，预演结束可重新打开文件恢复折叠。
3. 每课按候选讲稿的时段推进。讲者备注标出每页时间和投放方式，参见[讲稿与投屏对照](../../../08_项目维护/07_讲稿与投屏对照.md)。
4. 授课前用实际投屏设备走读，同时确认发放材料和独立作答时长。准备时参考[案例原始材料](../../../03_贯穿案例/招聘助手/01_模拟材料.md)和[A01–A10 接力任务](../../../03_贯穿案例/招聘助手/04_全课程示例与接力任务.md)。
