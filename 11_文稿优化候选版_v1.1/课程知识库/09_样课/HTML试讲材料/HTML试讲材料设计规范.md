# HTML 试讲材料设计规范与制作计划

**版本 v1.0 · 2026-11-16 · 适用于需求工程课程试讲**

[HTML 示范课件《把「更快」写成可验收的需求》](requirement-engineering-demo.html)展示了投屏风格和互动方式。示范使用模拟审批案例。在 GitHub 打开文件后，下载原始 HTML，再用桌面浏览器打开即可离线演示。三节样课及全课程已经有配套 HTML。候选课件与同版讲稿同步维护，正式启用依照本文走查。

## 1. 从定稿讲稿出发

每节课沿用[三节样课](../README.md)的 25 分钟预算，包含讲解、练习、讨论和反馈。先从定稿讲稿中找出学员要练习的判断，以及讲师用来检查判断的作品或回答。再写逐页安排，每页记录对应的讲稿段落、屏上信息、讲者提示、揭示时机和预计用时。学员先独立作答，讲师再展开参考答案，课堂按[试讲与开课计划](../../08_项目维护/05_试讲与开课计划.md)收集作品、用时与常见误解。

| 常用页面 | 屏上放什么 | 讲师怎么用 |
| --- | --- | --- |
| 开场 | 一句业务原话、必要背景、一个问题 | 请学员先说第一反应，给后续判断留出空间 |
| 追问或判读 | 两三张卡片，内容可逐项揭示 | 听到学员的理由后，再展开示例或关键线索 |
| 案例与证据 | 一组能改变判断的材料，标明来源或模拟性质 | 说明观察到什么、假定了什么、还缺什么 |
| 现场推演 | 可改变的条件，以及会随之变化的结果 | 改条件之前先请学员预测，变化之后再问原因 |
| 核对与讲评 | 判定口径、反例或边界案例 | 让学员用同一口径解释不同结果 |
| 迁移练习 | 新情境、作答要求、按需展开的示例 | 先收答案，再展示示例并回扣本课判断 |

表中的页面可以合并或重复。页数以讲解节奏为准，示范文件的六页对应一个短案例。适合做互动的地方是改一个条件就会改变判断的地方。示范第 4 页允许切换申请类型、调整时限，并同步显示达标比例和验收文字。学员可以据此讨论，数据刚好达标时，业务是否愿意接受修改后的承诺。

## 2. 版式与交互约定

| 项目 | 采用方式 |
| --- | --- |
| 投屏 | 桌面沿用 16∶9。每页围绕一个问题、判断或动作组织，长推导和补充提醒放进讲者备注 |
| 色彩 | 沿用示范的深绿外框（#111E1B）、暖白正文（#F6F4E9）和浅绿强调（#CCEDA5）。开场与收束可用深底，证据和规则页用浅底。结果用文字和颜色共同标明 |
| 字体 | 标题用系统中文衬线字体，正文用系统无衬线字体。标题、结论、卡片正文分三级，字号随画面调整 |
| 翻页 | 保留上一页、下一页、页码和进度。桌面支持左右方向键和全屏。焦点在滑块等控件时，方向键优先操作控件 |
| 逐步揭示 | 问题、线索和答案按教学顺序展开，示例答案默认折叠。讲者备注可随页切换，录屏或投屏前收起 |
| 窄屏 | 卡片和互动区可竖排，页面允许上下滚动。图表结论和状态有可读文字，操作按钮保持可点按 |
| 文件 | 每节课保存为单个 UTF-8 HTML，样式、脚本和模拟数据随文件保存。课程编号沿用 S01–S03，建议文件名为 S01-主题.html，并在逐页安排中记录对应讲稿版本 |

## 3. 讲稿与现有课件的同步顺序

1. **锁定输入。** 以本轮定稿讲稿为准，确认教学目标、案例数字、演示步骤、练习指令和讲评口径。示范采用独立的审批案例，实际课件按定稿中的案例与数据制作。
2. **先做一节并走查。** 建议先做 S03，它与示范中的阈值推演接近。先排完整节课，再做能改变学习判断的互动。讲师按讲稿完整走一遍，记录翻页时机、操作耗时和讲解中断点。
3. **复用到 S01、S02。** S01 可逐步揭示诉求中的事实、需要与方案。S02 可按顺序展示证据和反证。具体材料与揭示顺序以各自定稿为准。
4. **通过验收后启用。** 把验收通过的 HTML 纳入试讲，按原计划先收学员作品，再讲评。试讲后根据作品、用时和卡点修订，涉及案例规则或答案的改动同步回讲稿。

## 4. 试讲前逐项核对

- [ ] **对稿。** 页序、案例数字、计量口径、问题和参考答案与定稿一致。模拟材料有明确标记。
- [ ] **跑一遍。** 按 25 分钟预算走完讲解、练习、讨论和反馈。独立作答与反馈有实际停留时间。
- [ ] **查交互。** 从首页到尾页按键和点击均可导航。揭示、备注、全屏进入与退出可操作。每个有计算的互动至少核对默认值、边界值和一个无法达标的输入。控件操作时不会误翻页。
- [ ] **查设备。** 断网从本地文件打开，用实际投屏或录屏设备检查全屏、字号和裁切。再用手机竖屏打开，核对页面、图表与按钮是否可读可用。
- [ ] **查分发。** 课件能从样课索引找到，文件名与课时对应。按试讲安排发放学员页和讲评材料，避免在独立作答前展开答案。
