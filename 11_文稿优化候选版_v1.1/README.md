## 单独同步与使用

整体同步本文件夹，进入其中的 [课程知识库](课程知识库/README.md) 即可按目录阅读，也可以把它作为 Obsidian Vault 打开。文件保持完整解包结构，内部相对链接可在目录内使用。

HTML 需下载原始文件后用浏览器打开。每课为独立文件，支持离线翻页、讲者备注和按时揭示答案。投屏入口位于 [全课程 HTML 索引](课程知识库/09_样课/HTML试讲材料/全课程/README.md)。
