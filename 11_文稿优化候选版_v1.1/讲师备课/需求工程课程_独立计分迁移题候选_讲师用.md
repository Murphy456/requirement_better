# 需求工程课程 · 独立计分迁移题候选

> 本文件随公开仓库发布，主卷、备用卷及评分锚点均可见。可用于备课、试做和公开练习。正式陌生情境测评请另备未向学员公开的等难变式。

讲师用。试做或考试时只分发当时所需的题材，评分示例与另一套题由讲师保管。使用现有八维、100 分量规。独立迁移占总评 30%，具体难度由真人试做校准。

## 主卷 · 共享设备借用

### 第 0 分钟发给学员

某机构设有两个器材室，员工先预约便携投影仪，再到柜台取还。项目负责人说：“找不到设备就做一个预约 App，放进库存数据后能自动分配。”

| 材料 | 内容 |
|---|---|
| D01 项目负责人口述 | “上月大概三成借不到，主要是大家不知道库存。”没有统计来源。希望员工少往返、柜台少做重复登记。 |
| D02 柜台观察 | 本周三一次观察。两人带预约来取，其中一人发现设备仍在借出，回去协调会议。工作人员查过借还登记。观察员未覆盖另一器材室。 |
| D03 一页登记摘录 | A 库 09:00 预约 J01，设备 P01 实际 09:12 领出。A 库 10:00 预约 J02，设备 P02 尚未归还。A 库 10:30 直接到场 J03，P03 空闲且领出。B 库 11:00 预约 J04，员工取消。B 库 11:30 预约 J05，备注栏空白。样本来自方便提取，未标记与 D02 是否同一批。 |
| D04 当前规则 | 柜台实际领出、归还由管理员记录。普通员工只看本机构可借的器材及自己的预约；设备维修期间不可分配。目前可由管理员手工检查、电话通知。 |
| D05 外部依赖 | 资产台账由行政维护，能导出设备编号和维护状态，更新频率及接口可用性待查。现用纸面记录中，编号有时只写型号。 |
| D06 未定条件 | 有人提出“库存要实时”，取还登记和员工看到状态之间可接受的延迟未议定。预约占用何时释放、逾期如何处理也待确认。 |

你有 90 分钟，提交一份精简需求包，至少包括以下内容。数值或规则证据不足时，标出待确认及证据取得方式。

1. 定义问题、角色、范围与成功口径。
2. 给两条陈述写证据与局限，提出最小取证动作。
3. 画或写一个能走读的模型，含正常、维修或逾期。
4. 比较至少两个做法，写首版取舍、依赖与复议条件。
5. 写一条功能要求和一条有业务含义的质量候选。
6. 给两条可观察验收，包含一个主要异常。
7. 留一条可追踪关系和变更分析。
8. 写有效果基线、分母与可比条件的观察计划。

前 60 分钟处理已有资料。收到最后的变更卡后保留原有判断，并写修改所在。可以用课程模板，也可以自拟表格。

### 第 60 分钟变更卡

行政发来一份临时停用清单，按设备编号列出刚发现需检查的投影仪。命中清单的设备须立即暂停新分配。已经被预约的设备由管理员联系员工改配，已领出的设备由管理员发出归还通知。旧预约有些只记型号。请分析受影响的状态、规则、数据和验收，并说明无法确认设备编号时暂时怎样处理。更新频率、恢复条件和责任人由你写成待确认问题。

### 讲师评分锚点

沿用课程现有 R1–R8 权重与等级。以下是可观察的 2 级表现和升到 3 级需要出现的证据。即使采用另一方案，也按作品理由和一致性评分。

| 维度 | 2 级证据 | 3 级增量 |
|---|---|---|
| R1 问题与范围 | 说明借用者、柜台与行政的任务，区分可见库存与实际可借。 | 有具体成功口径及改判，使设备数量与状态管理问题可检验。 |
| R2 证据 | 不能由五行或口述得出全机构三成，空白用待查。 | 检查样本依赖、记录重叠与覆盖，说明什么证据会改变方案。 |
| R3 模型 | 区分预约、实际领用、归还、维修，异常可走通。 | 用“命中临时停用清单，但旧预约只记型号”验证模型，加条件或保守人工路径。 |
| R4 取舍 | 对比人工核对或通知与系统化方案，点明台账依赖。 | 说明在什么证据下重议，区分收益估计、成本、可开始工作及上线条件。 |
| R5 表达 | 功能前提、状态可见结果与延迟候选可讨论，标待协商。 | 限定起止、数据与恢复依赖，避免擅定阈值，同时留下选择空间。 |
| R6 验收 | 给可复现的正常借用和维修或返还异常。 | 说明未分配、已预约与已领出设备、存量缺号如何分别验收。 |
| R7 追踪 | 有目标到条目及验收，指出变更影响。 | 保留原决定，列状态、字段和回归路径，给出待核生效条件和决定者。 |
| R8 效果 | 写一次尝试借用为分母的结果观察与基线。 | 区分取消、重复查看、设备维修等变量，说明观察局限和下一轮决策。 |

可接受的初步方案是先对一处器材室做真实可借状态与人工通知的短试点。允许暂缓自动分配，直到台账更新、设备编号和回收规则可核实。可以提出其他合理组合。发现越权可见、把“没有归还记录”直接认定逾期事实等问题时，按总量规处理并留下依据。

## 备用卷 · 社区服务排班

本卷独立于主卷，首次释放时使用。时长、交付八项、计分及发卡时点同主卷。

### 第 0 分钟发给学员

社区服务站安排志愿者做接待和物资登记。负责人说“临时找人很慢，应该自动排所有班”。管理者、志愿者和前台协调员分别负责确认班次、报名、交接与记录。

| 材料 | 内容 |
|---|---|
| E01 负责人说法 | “差不多一半班次都要临时补人。”没有原始统计。希望减少服务开始前的空岗。 |
| E02 现场观察 | 周一上午，协调员在开场前发现一位志愿者没到，两次发消息，请另一人来帮忙。只观察这个班。 |
| E03 方便样本 | 周一早班 Q01，已报名，实际到场。早班 Q02，已报名，现场缺人。周一晚班 Q03，临时补上。周二早班 Q04，取消。晚班 Q05，签到记录空白。没有证据说明与 E02 是否同一批。 |
| E04 当前规则 | 物资登记需培训，接待可由新志愿者参与。志愿者只看公开班次和自己的报名信息。协调员可以找候补，正式换班由管理者确认。 |
| E05 外部依赖 | 培训名单由另一部门维护，可导出但更新时点未明。部分旧记录只有姓名没有编号。 |
| E06 未定条件 | “缺口要尽早提示”尚无定义。临时退出的截止时间、通知及重试方式待协商。 |

### 第 60 分钟变更卡

新规则提议，从下周开始，首班志愿者不得独立承担物资登记，须有一位当日到岗的熟练志愿者同时在班。培训名单只有“培训完成”，缺首班标记。请写受影响的模型、数据、规则、旧排班与验收，并区分“新规则建议”与“生效已确认”。

### 讲师评分锚点

R1 看候补任务和真实空岗口径。R2 核对“签到空白”与“未到”的区别及采样限制。R3 能演算报名、确认、到场和临时补位。R4 兼顾手工候补、提醒与自动方式，写培训状态依赖。R5 用可观察时点说明缺口提示，把阈值由谁确认落到记录。R6 至少能验正常班次和培训或首班例外。R7 能保留前后版本并指出旧排班和新规则的回归范围。R8 以可比班次估计空岗和人工协调用时，避免从方便样本给出全站结论。3 级需要反证、结果边界及可执行的复议条件，适用主卷同一评分标准。
