# CASE-01 星桥设备服务的工单对账准备

**全部内容为课程原创教学模拟。** 企业、角色、访谈、观察记录、规则、数据、阈值和决策均非真实调研结论。编号用于学习需求追踪，不代表客户批准。

星桥设备服务管理A、B两个园区的维修工单。维修流程在线上系统中运行，资产台账由另一团队维护；财务人员需要准备月度核对材料。开场诉求是：“给系统加一个导出Excel功能，每个月方便对账。”

学员的任务是判断需要改变什么、如何取得依据、哪些内容可进入首版，并给出可供团队评审的需求包。不是直接照着参考答案开发，也不是证明导出一定正确。

## 角色

| 角色 | 关注 | 在案例中的责任 |
|---|---|---|
| 财务经办 | 数据可核对，月份含义明确 | 说明实际工作、核验字段用途 |
| 维修班组 | 不重复填报，返修可处理 | 解释状态转换和登记负担 |
| 园区主管 | 工作可见，权限清楚 | 确认园区范围，批准重新打开工单 |
| 业务负责人 | 降低核对准备中的返工 | 决定范围和接受的业务风险 |
| 信息管理人员 | 权限与数据口径一致 | 确认授权及字段来源 |
| 交付团队 | 能实施、能测试、能维护 | 评估技术方案与质量目标可行性 |

## 分批释放材料

第一批E01：用于发现初始判断；第二批E02—E05：用于修订问题、分析证据和建模；第三批E06：用于暴露跨期与重开问题；最后注入CR-01：用于变更分析。

[原始材料](01_原始材料.md)与[参考分析](02_分析与建模参考.md)分开。自学者先写自己的分析再阅读参考。参考答案是有条件的可行方案，不是唯一标准。

## 编号与阅读顺序

E表示教学证据，H表示假设，BR表示模拟业务规则，DEC表示教学决策，REQ表示需求，AC表示验收，CR表示变更。先读材料，再做模型，再看[需求规格](03_需求规格与验收参考.md)，最后做[变更与效果](04_变更与效果验证.md)。所有学习成果沿同一需求包修订，保留版本差异。
